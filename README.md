# one-emoji-smile

A program that writes exactly one emoji to `/output/entry.txt` — the one most likely to make a stranger smile.

## Run it

```sh
node main.ts
```

It writes a single emoji (🌈, a rainbow) to `/output/entry.txt`:

> 🌈

A rainbow is a small gift of colour and hope: warm at first glance, universal across ages and backgrounds, clearly picked rather than the default smiley, and perfectly right coming from a stranger.
